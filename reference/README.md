# Reference — 주제별 딥다이브

각 단계 본문의 운영 흐름을 유지하기 위해, 특정 주제를 깊이 파야 할 때는 여기에 주제 단위 노트로 누적한다.

## 작성 규칙

- 파일명: 주제 이름 소문자 (예: `etcd.md`, `cni.md`, `rbac.md`)
- 단계 노트에서 "더 깊이"가 필요해진 시점에 만든다 — **미리 만들어두지 않는다**
- 단계 노트에서 이 문서로 링크를 걸어 연결한다

## 노트 템플릿

```markdown
# <주제>

## 한 줄 정의
## 핵심 개념
## 운영에서 자주 마주치는 것 (실수, 한계, 함정)
## 관련 단계
```
